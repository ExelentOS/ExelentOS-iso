## About ExelentOS

ExelentOS is a custom GNU/Linux distribution aimed at providing a user-friendly experience with the latest KDE Plasma 6 desktop environment. Built on the solid foundation of Arch Linux, it offers a seamless and efficient computing experience for both new and experienced users.

## Features

- **KDE Plasma 6**: Experience the cutting-edge features of the latest KDE desktop environment.
- **Arch Linux Base**: Enjoy the flexibility and power of Arch Linux with a user-friendly setup.
- **Pre-configured Environment**: Out-of-the-box configurations for enhanced usability.
- **Regular Updates**: Stay up-to-date with the latest software and security patches.

## Getting Started

To get started with ExelentOS, download the latest ISO from the [download page](https://exelentos.github.io/download) and follow the installation instructions below.

## Installation

1. **Download the ISO**: Get the latest version from the [download page](https://exelentos.github.io/download).
2. **Create Bootable Media**: Use tools like [Rufus](https://rufus.ie/) (for Windows) or the `dd` command (for Linux) to create a bootable USB drive.
3. **Boot from USB**: Restart your computer and boot from the USB drive.
4. **Follow Installation Guide**: The installer will guide you through the installation process.

For detailed installation instructions, refer to the [official documentation](https://exelentos.github.io/docs/installation).

## Usage

After installation, you can start using ExelentOS immediately. For tips and tricks on getting the most out of your new system, check out the [user guide](https://github.com/exelentos/exelentos-iso/wiki).
